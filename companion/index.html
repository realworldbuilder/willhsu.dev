WoW Companion

My World of Warcraft character on my phone. One addon in the game, one server on the Mac mini, one app on the home screen: who she is, every spec's loadout, her gear and stats, every keybind on every bar, the spec guide with my own keys on each step, and a journal that writes its own chapter at night. Built in one evening, as an MVP, on retail. Forever next.

The idea

I'd asked for a "WoW Forever Companion iPhone app", something like Scarletfire's page but live and in my pocket, with the roleplay side Rambleon has. Addons have hard limits: no network, no files of their own, and the game only writes their saved data on /reload or logout. So the shape is a relay. The addon collects, the game writes the file, the mini reads it over ssh, the phone reads the mini.

It is a standalone thing, but almost nothing in it is new. The capture is RP Spec, the addon I built the night before (spec, talents, gear, every bar and binding, a journal). The chat capture is Rambleon's. The look code and the portrait are Mogshot's. The companion takes those pieces, renames them, adds the two things they lacked, and puts a phone in front.

The flow

The gameThe Companion addon reads what the client tells it: spec, loadouts, gear, bars, journal, chat. Nothing protected, nothing in combat.
→
SavedVariablesOne file per account, Companion.lua, written by the game on /companion save, /reload or logout. Plus the Screenshots folder.
→
The miniEvery 15 s: stat the file over ssh, read it when it changed, parse the Lua as data, pull new screenshots, rebuild the model.
→
The phoneA home-screen web app on the Tailscale address. Five tabs, polls every 30 s, shows how fresh it is.

WoW runs on the MacBook; the mini has no game. The two talk over the tailnet, so the app only works on my own devices.

The spec

Addon
addon/Companion, retail 12.1.5 (Interface: 120105), SavedVariables CompanionDB, slash /companion and /comp. Seven Lua files, one spec guide (Feral), 50 checks under a stub client.
Server
server.mjs, Node 26, no dependencies. Port 4210 on localhost and the Tailscale address. launchd com.william.wow-companion.
App
Vanilla HTML, CSS and JS, hash-routed bottom tabs, safe areas, apple-mobile-web-app-capable, a manifest and a home-screen icon. No framework, no build, no service worker (plain http).
Sync
ssh with 5 s connect timeout, a shared control connection, 15 s between checks, 60 s after three failures. A sleeping MacBook turns the header red; the last file is kept on disk so a restart serves at once.
Snapshot
character (name, realm, level, race, class, spec, faction, guild, title, ilvl, mounts), stats, gear with bonus ids, talents with the game's own descriptions and the import string, every spec's saved loadouts, every bar and form page with its binding, the guide.
Journal
level, zone, boss, achievement, death, mount, quest, spec, note, mark, photo, and chat: /say, /emote, /yell, and party or raid if asked. Never whispers.
Pictures
The hero is the last /companion photo, a screenshot with the UI hidden. Otherwise Transmogify renders her MOG2 code, with her barber choices from a side file until she sits in a chair.
Icons
Wowhead's icon name by spell or item id, the icon CDN, cached on the mini. The game's own icon by file id through Transmogify as the fallback.
Chapter
claude -p with the newest day of the journal, chat included: about 150 words in her voice, 11 seconds, cached per day.
Notes
Typed on the phone, kept on the mini, shown in the timeline marked "from your phone". They don't reach the game yet.

The tabs

  • Character. The photo, her class colour on the name, level and spec, item level, the stats grid, the gear doll in quality colours with item level per slot (each piece links to Wowhead), and the Mogshot code with a copy button.
  • Build. Every saved loadout for every spec with Copy, which is tonight's one phone-to-game path: copy the import string on the couch, paste it in the talent window. Below it the talents in hero, spec and class groups, tap for the full description.
  • Keys. Cat Form, Bear Form, Caster Form, the Shift bar and the Ctrl bar as a keyboard, with the spell's icon on the key I bound it to. Tap a key for the tooltip and the other keys it's on.
  • Guide. The Feral guide, opener and priorities and "when it goes wrong", each step wearing the key I actually press. Talents marked learned, next, later. The habits. A warning for any step not on a bound key.
  • Journal. Newest day first, pictures inline, what was said in character as speech bubbles, a box to write a note, and a button that has Claude write the chapter.

In the game

/companion
who you are, one line
/companion snap
take the snapshot now (it also happens on login, level, spec, talent, gear, bar and binding changes)
/companion save
write the file now (reloads the UI); the phone sees it within 15 s
/companion note <text>
a line in the journal; mark does the same with a picture
/companion photo
a screenshot with the UI hidden, the phone's hero picture
/companion mog
the Mogshot code
/companion rp on|off
record what is said around you; rp party on adds the group
/companion shots, journal
pictures at level ups and marks; the journal itself

The rules are Rambleon's and RP Spec's: only plain values are stored, never secret values, nothing read in combat except chat (which isn't protected), no combat log, no protected API, no automation. The addon can't send anything anywhere. It writes a file and the mini comes to get it.

Working around the addon limits

Out of the game (built)
  • SavedVariables are the only door, and the game opens it on reload or logout. /companion save is a reload.
  • The mini polls the file's modification time over ssh and only reads it when it moved.
  • Screenshots come the same way, paired to journal entries by the second they were asked for.
  • The header says "synced 4 min ago" so I know what I'm looking at.
Into the game (not yet)
  • An addon can't read a file at runtime, but a Lua file loaded as code is read on every reload. Rambleon already does this for its chapters. An Inbox.lua could carry phone notes and the day's plan into /companion inbox.
  • A keystroke bridge on the MacBook (osascript, with Accessibility granted to sshd) would let the phone /em or /companion save for real.
  • The Battle.net Profile API would cover characters without the addon.
